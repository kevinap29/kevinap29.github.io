Hari ini saya resmi merilis **[Antigravity Custom Agents](https://github.com/kevinap29/antigravity-custom-agents)** secara sumber terbuka (open source)—sebuah framework rekayasa perangkat lunak multi-agent yang dirancang untuk **Antigravity** dan **Gemini CLI**.

Sepanjang setahun terakhir berkolaborasi dengan asisten AI otonom, pembengkakan token (context rot) dan ketiadaan guardrail domain yang terstandar sering menjadi kendala utama. Repositori ini mengatasi masalah tersebut dengan mengubah prompt acak menjadi tim rekayasa perangkat lunak yang berdisiplin dan terstruktur.

### Apa Saja yang Disertakan:

- **9 Custom Agent Terspesialisasi**: Peran khusus untuk Arsitektur Sistem, Frontend/Mobile, Backend (.NET), Database, DevOps, QA Code Reviewer, Debugging, Dokumentasi Teknis, dan Lead Orchestrator.
- **3 Skill Domain Siap Produksi**: Pola teruji untuk `.NET WebForms`, `Frontend & Mobile Patterns` (SvelteKit 2 + .NET MAUI Blazor), dan deployment VPS `Portainer/Harbor`.
- **Plugin Penghemat Token RTK**: Hook pre-command yang memadatkan output terminal hingga 70–90%, menghemat kuota token untuk penalaran mendalam.
- **Profil Pengembang Global (`GEMINI.md`)**: Panduan aturan terpusat yang menegakkan DRY, KISS, integritas DB-First, dan adaptasi shell Windows/Linux.

Kunjungi repositori resminya di [GitHub](https://github.com/kevinap29/antigravity-custom-agents) untuk meningkatkan efisiensi alur kerja agentic Anda!
