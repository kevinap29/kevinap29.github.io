Today marks the open-source release of **[Antigravity Custom Agents](https://github.com/kevinap29/antigravity-custom-agents)**—a turnkey multi-agent engineering framework designed for **Antigravity** and **Gemini CLI**.

Over the past year of co-creating applications with autonomous AI coding tools, token bloat and lack of domain guardrails consistently emerged as the primary friction points. This repository bridges that gap by transforming unpredictable AI prompts into a disciplined software development team.

### What's Included:

- **9 Specialized Custom Agents**: Roles dedicated to Architecture, Frontend/Mobile, Backend (.NET), Database, DevOps, QA Review, Debugging, Documentation, and Lead Orchestration.
- **3 Production-Tested Domain Skills**: Reusable patterns for `.NET WebForms`, `Frontend & Mobile Patterns` (SvelteKit 2 + .NET MAUI Blazor), and `Portainer/Harbor` Linux deployments.
- **RTK Token Optimizer**: An integrated pre-command filter hook that reduces command output noise by 70–90%, preserving context depth across long engineering sessions.
- **Global Developer Profile (`GEMINI.md`)**: A centralized rulebook enforcing DRY, KISS, DB-First integrity, and platform-specific shell standards.
